# 陣前招親 — 手繪塗鴉成景

本版本僅在本機使用，依使用者要求不再上傳或同步至 Sites。無人物、兵馬；天空有使用者追加的少量簡筆飛鳥。

## 開啟

在此目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4173/ 。瀏覽器需支援 WebGL 2；不可直接以 file:// 開啟 ES modules。

直接開啟 `http://127.0.0.1:4173/`。不需要網址參數或控制面板；首頁先在純白底上逐筆繪製原塗鴉，旋轉散開成空間線稿後，才疊上製作人與主演題字，再呈現《陣前招親》與故事簡介。潑墨串起文字進退場，最後繼續旋轉成完整山寨。舊網址參數不再控制畫面。

## 手法

使用未修改的使用者塗鴉開場；從原圖取出綠、藍、棕等筆畫色彩，將筆觸放回原圖位置，再旋轉並重組成穆柯寨。完成景由披麻皴、斧劈皴、破墨、點苔與礦物彩墨筆觸構成；不再抽取模型的建築邊線。山體寬筆兩側都貼合地形，避免寬筆被隱藏地形切掉。寨門、塔樓和屋舍四面均有筆觸。

最終畫面使用 Three.js 連續毛筆帶：深色墨線以可變粗細的筆壓呈現，石青、石綠、赭金及朱紅寬筆層疊成國畫彩墨。整幅有程序紙色與彩色筆刷，沒有風景照片或實心模型光影。隱藏的三維骨架只用來定位與深度遮擋，避免後方線條穿透寨門。牌匾文字不顯示。只有開場使用原始圖片；前版 landscape.png 保留為歷史素材，目前程式不載入它。

## 場景與操作

| 按鍵 | 場景 | 劇本用途 |
| --- | --- | --- |
| 1 | 穆柯寨內 | 穆桂英耍劍出台、探馬來報 |
| 2 | 寨外山道 | 出營應戰、楊宗保闖寨 |
| 3 | 陣前交鋒 | 都馬調對唱、槍法交鋒；旗幟線條風勢加強 |

- 畫面沒有按鈕、滑桿或說明。預設開場約40秒：先6秒沿原圖筆跡依序畫出地面、山勢、河流、雲；旋轉約28%時開始製作人與主演題字，接著顯示故事名稱與完整簡介。文字期間保留緩慢轉動的淺線稿，讀完後才繼續旋轉成彩墨山寨。所有文字退場後僅保留背景。
- 空白鍵播放／暫停／重播，雙擊畫面也可操作。
- 拖曳未完成畫面，可以前後查看線條成形；完成後可持續水平360°旋轉，拖曳一個畫面寬約一圈。左右方向鍵每次旋轉15°。攝影機沿途自動避開地面。
- 滾輪向上拉近、向下拉遠，平滑縮放範圍為0.65–2.6倍。縮放不改變攝影機的安全旋轉路徑，也不重建筆畫；暫停風景時仍可縮放。重播會回到原始倍率，Ctrl／Command＋滾輪仍保留瀏覽器縮放。
- 按 F 進入／離開全螢幕，Esc 返回。
- 雲層緩慢飄移、水紋沿彎曲河道流動、旗布起伏而旗杆不動、簡筆鳥群繞行與振翅。按 P 可暫停／繼續這些動態。
- 寨外地面有兩段蜿蜒鎖鏈，寨內另有一小段；細密小鏈環交錯相扣並貼合地形。寨外兩座營火包含柴木、石圈、明顯跳動的大火舌、上飄火星與逐漸散開的灰墨煙線，動畫同樣由GPU處理。
- 換景以線條淡出、淡入銜接，避免攝影機快速運動干擾演員。

## 16:9 現場輸出

構圖以 16:9 設計，依最新指定直接滿版：畫布填滿整個視窗，不留黑邊或頁面邊距，非16:9視窗會拉伸完整構圖而不裁切。Windows 使用「延伸」顯示模式，外接螢幕設為 1920×1080，將瀏覽器移至外接螢幕後按 F11。若之後提供 LED 原生尺寸，可再適配。

筆畫一次上傳GPU；旋轉、換景與重播重用資料。雲、水、旗與鳥由頂點/片段著色器更新，不在每幀重建幾何。筆刷採單次雙面繪製，省去透明材質的重複pass。繪圖上限約210萬像素、DPR上限1.25；有焦點且持續低於40FPS時逐級降低渲染比例，穩定後恢復。隱藏分頁停止循環，暫停動態且無操作時停止重繪；效能數據僅存在canvas dataset，不顯示於舞台。

## 片頭文字設定

編輯 `dist/intro-config.json` 後重新整理網頁，即可套用文字與時間，不需要網址參數。

- `credits`：依右到左排列，每組的 `role` 是小字職稱、`name` 是大字姓名。預設為「製作人／土撥鼠哥」「主演／南方薪傳」，最多4組，每組職稱6字、姓名8字。
- `showAtRotation`：開始顯示文字時的旋轉進度，預設 `0.28`。原始塗鴉繪製期間不顯示文字。
- `writingSeconds`、`holdSeconds`、`fadeSeconds`：分別為題字寫入、完整停留、墨跡消散的秒數。
- `story.title`、`story.synopsis`：接在製作人／主演之後的故事名稱與簡介。各自最多12／240字；舞台上建議簡介在100字以內。預設完整保留使用者提供的故事原文。
- `story.writingSeconds`、`story.holdSeconds`、`story.fadeSeconds`：故事題名／簡介的寫入、閱讀、退場秒數，預設6／10／1.3秒。
- `storyGapSeconds`：工作人員題字與故事之間的間隔，預設0.6秒。
- `splashEnabled`、`splashIntensity`：潑墨串場開關與濃度，預設開啟、濃度1。
- `drawingSeconds`、`rotationSeconds`：原塗鴉繪製與正常旋轉的秒數；文字閱讀段會自動延長線稿過渡。
- `enabled: false`：關閉製作人／主演題字；`story.enabled: false` 關閉故事。兩者都關閉時，回到17秒塗鴉成景。
- `fontScale`、`story.fontScale`：題字與故事簡介的尺寸倍率，預設1.15／1.45。
- `story.removePunctuation`：預設false，保留使用者原文的全部標點。預設61字依語意排成十個直欄，人名不跨欄拆開。
- `story.columns`：可選的自訂直欄字串陣列，依右到左排列；全部欄拼回後必須與簡介相同，否則回到自動排版。
- `splashAccentColor`、`splashAccentAmount`：朱紅墨色與點綴比例，預設`#a83224`／0.22；設為0可只用黑墨。
- `inkColor`：六位十六進位墨色。
- `letteringStyle`：預設`calligraphy`，採青柳衡山行書；`procedural`可切回筆畫路徑毛筆版本，該字庫目前僅涵蓋漢字，不適用含標點的簡介。

初始化與原塗鴉的底色全部使用純白。依使用者後續要求，題字使用書家青柳衡山親筆書寫的「衡山毛筆行書」，不是標楷體，也不是王羲之字型。原字形的粗細、連筆、收鋒與飛白予以保留，再沿墨跡骨架顯露、滲染、積墨與消散。骨架動畫是藝術化筆跡生長，並非歷史書寫筆順的精確重演。所有文字維持繁體，載入前用實際非空字形清單檢查每字；不讓缺字自動混用系統字體。

行書WOFF2及字元清單存於`dist/assets/fonts/`，官方來源與說明見`KouzanGyousho-SOURCE.md`。字體只由本機載入，不需安裝到Windows，也不需外部CDN。使用者提供的原文61字包含全形逗號及句號；目前所需55種漢字與兩種標點全部有字形。
黑墨與少量朱紅的潑墨串接三段轉場；閱讀期間下緣與邊角的墨流持續變形、聚散，中央文字保持清楚。整個過場使用一個額外畫面批次，沒有每幀重建幾何；文字與過場結束後全部隱藏，不增加完成場景的繪製批次。

備用程序毛筆的漢字筆畫資料在`dist/assets/ink-strokes/`，附來源與授權；從Hanzi Writer資料只保留筆順中心線，外形由此專案的毛筆程序生成。預設文字合併成小檔，修改JSON後會從本機分片字庫補載所需文字，不連外。若設定字不在字庫，開發者主控台會列出缺字並停用該段題字，場景仍播放；不擅自替換為一般字型。

## 原始碼

- `dist/app.js`：攝影機、提示切換、純線條渲染、操作與固定構圖。
- `dist/reveal.js`：原始筆畫取樣、筆觸重描與旋轉成景。
- `dist/brush-strokes.js`：可變粗細毛筆帶、彩墨邊緣與全幅紙色。
- `dist/sketch-fortress.js`：屋瓦、飛簷、斗拱、磚石、門扇與旗幟筆畫。
- `dist/sky-birds.js`：簡筆鳥群與GPU飛行、振翅參數。
- `dist/ground-chains.js`、`dist/campfires.js`：地面鎖鏈與營火筆畫。
- `dist/opening-drawing.js`：依地面、山勢、河流、雲追蹤原圖筆跡，逐步揭露開場塗鴉。
- `dist/intro-config.json`、`dist/intro-settings.js`：可編輯片頭設定及安全預設值。
- `dist/ink-credits.js`：直式毛筆題字排版、筆順顯露與消散。
- `dist/ink-calligraphy-glyph.js`、`dist/calligraphy-face.js`：本機行書載入、字形覆蓋檢查、原筆形墨跡生長。
- `dist/ink-glyph-brush.js`：備用程序毛筆；沿筆順中心線生成可變筆壓、飛白、積墨與滲邊的字形。
- `dist/ink-stroke-data.js`：本機漢字筆順資料載入與快取。
- `dist/story-intro.js`：故事題名及完整簡介的直式排版。
- `dist/intro-timeline.js`：塗鴉、緩慢旋轉、題字、故事與成景的共用時間軸。
- `dist/ink-transition.js`：三段黑墨／朱紅潑墨，以及閱讀期間持續流動的墨色。
- `dist/sketch-landscape.js`：山形輪廓、排線、松樹、河流與雲朵筆觸。
- `dist/environment.js`、`dist/fortress.js`：不直接顯示的地形與建築骨架，僅供筆畫定位。
- `dist/vendor/`：隨專案附帶 Three.js 0.181.2，不需外部 CDN。

目前為舞台美術原型，古風山寨以劇本意象設計，並非考據復原。正式演出前應以現場電腦、投影或 LED 確認亮度、效能與換景節奏。
