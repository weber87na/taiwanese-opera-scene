# 一筆，成山河

以使用者原始塗鴉與依其構圖生成的山河圖製作 Three.js 互動原型。

## 開啟

在此目錄執行 `node server.mjs`，瀏覽 http://127.0.0.1:4173 。不要直接用 file:// 開啟，瀏覽器會限制 ES modules 與圖片讀取。

## 操作

- 按「播放旋轉」播放約 10 秒的完整變化，可隨時暫停。
- 向右拖曳畫面，或使用進度滑桿前後查看。
- 「回到塗鴉」回到原始圖片；完成後可「再看一次」。
- 全螢幕保留控制列。最後畫面支援小幅滑鼠視差與細微水面流動。
- 系統偏好減少動態時，播放放慢且停止水面動態。無自動播放。

## 實作範圍

這是 2.5D 圖片浮雕、真實 3D 筆畫點雲、碎片重組與材質揭露的混合效果，不是完整可自由繞行的山河 3D 模型。開場圖片保持原檔；筆畫點雲由原圖所有非白色像素取樣；完成圖由內建 imagegen 依相同構圖生成，提示詞見 ASSET-PROMPT.txt。所有圖片與 Three.js 0.181.2 均隨專案提供，本機預覽不需外部 CDN。

## 檔案

- `dist/index.html`、`styles.css`：介面。
- `dist/app.js`：Three.js 場景、GPU 轉換與互動。
- `dist/assets/doodle.png`：未修改的使用者原圖。
- `dist/assets/landscape.png`：生成的完成場景。
- `dist/vendor/`：固定版本 Three.js 與授權。
