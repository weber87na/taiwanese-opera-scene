# 陣前招親 — 手繪塗鴉成景

本版本僅在本機使用，依使用者要求不再上傳或同步至 Sites。依最新要求，城內外已移除人物，只保留舞台背景與少量簡筆飛鳥，不加入百姓、士兵或馬匹。

## 開啟

在此目錄執行 `node server.mjs`，開啟 http://127.0.0.1:4173/ 。瀏覽器需支援 WebGL 2；不可直接以 file:// 開啟 ES modules。

直接開啟 `http://127.0.0.1:4173/`。不需要網址參數或控制面板；首頁先在純白底上逐筆繪製原塗鴉，旋轉散開成空間線稿後，才疊上製作人與主演題字，再呈現《陣前招親》與故事簡介。潑墨串起文字進退場，最後繼續旋轉成完整山寨。舊網址參數不再控制畫面。

## 手法

使用未修改的使用者塗鴉開場；從原圖取出綠、藍、棕等筆畫色彩，將筆觸放回原圖位置，再旋轉並重組成穆柯寨。完成景由披麻皴、斧劈皴、破墨、點苔與礦物彩墨筆觸構成；不再抽取模型的建築邊線。山體寬筆兩側都貼合地形，避免寬筆被隱藏地形切掉。寨門、塔樓和屋舍四面均有筆觸。

最終畫面使用 Three.js 連續毛筆帶：深色墨線以可變粗細的筆壓呈現，石青、石綠、赭金及朱紅寬筆層疊成國畫彩墨。整幅有程序紙色與彩色筆刷，沒有風景照片或實心模型光影。隱藏的三維骨架只用來定位與深度遮擋，避免後方線條穿透寨門。牌匾文字不顯示。開場使用原始塗鴉；Q 土撥鼠另使用依參考圖生成的透明水墨角色圖集，場景其餘筆觸維持程序繪製。前版 landscape.png 保留為歷史素材，目前程式不載入它。

- 畫面沒有按鈕、滑桿或說明。預設開場約40秒：先6秒沿原圖筆跡依序畫出地面、山勢、河流、雲；旋轉約28%時開始製作人與主演題字，接著顯示故事名稱與完整簡介。文字期間保留緩慢轉動的淺線稿，讀完後才繼續旋轉成彩墨山寨。所有文字退場後僅保留背景。
- 成景後預設啟用 0 自動鏡頭，約五分鐘慢轉一圈，遠近與高度以不同週期緩慢變化。1～5 以平滑環繞過渡切換定鏡，主鍵盤和數字鍵盤皆可用；切換不重建場景，也不重設日夜或四季。拖曳、方向鍵、滾輪或 +/- 會暫停自動運鏡，0 再接續。P 與隱藏分頁暫停自動運鏡。
- Q 觸發約4.05秒的水墨 marmot（旱獺／土撥鼠），依參考保留小圓耳、寬鈍鼻口與厚實身軀，改以大塊濃淡墨、赭黃洗色、暈染與飛白呈現。六姿態透明圖集前四格以12fps循環四腳小跑，軀幹水平、腳掌貼地，沿寨外中央山道避開營火；2.78秒抵達大門，才轉為起身、雙腳站穩，清楚停留後淡出。圖集共用一張材質，每格腳底分別對齊，同一時鐘暫停與重播，不在每幀重新建構幾何。接著以置中小視窗有聲播放 `dist/assets/marmot.mp4`，高度不超過視窗72%，完整保留直式比例、不裁切，周圍仍可看見山寨。右上角不顯示 Esc 或返回按鈕；鍵盤 Esc 可提前返回，播畢自動恢復原本鏡頭、縮放與動態狀態。若瀏覽器阻擋自動播放會顯示「播放影片」。影片約10.1秒、404×720、H.264＋AAC，已存於專案，可離線播放；[原影片](https://www.youtube.com/shorts/iL46oozvBCc) 及來源紀錄保存在 `marmot.source.json`。
- 空白鍵播放／暫停／重播，雙擊畫面也可操作。
- 拖曳未完成畫面，可以前後查看線條成形；完成後可持續水平360°旋轉，拖曳一個畫面寬約一圈。左右方向鍵輕按小幅平滑轉動，按住時以每秒36°連續旋轉，放開後平順停下；切換視窗或開始滑鼠拖曳會停止鍵盤旋轉。攝影機沿途自動避開地面。
- 滾輪向上拉近、向下拉遠，平滑縮放範圍為0.65–2.6倍。縮放不改變攝影機的安全旋轉路徑，也不重建筆畫；暫停風景時仍可縮放。重播會回到原始倍率，Ctrl／Command＋滾輪仍保留瀏覽器縮放。
- `+`／`-`（含數字鍵盤）也可平滑放大／縮小，每次約8%；主鍵盤的 `=` 可直接放大，不必按Shift。範圍同滾輪，Ctrl／Command＋`+`／`-`仍交由瀏覽器縮放。
- 按 F 進入／離開全螢幕，Esc 返回。
- 雲層緩慢飄移、水紋沿彎曲河道流動、旗布起伏而旗杆不動、簡筆鳥群繞行與振翅。按 P 可暫停／繼續這些動態。
- 寨外地面有兩段蜿蜒鎖鏈，寨內另有一小段；細密小鏈環交錯相扣並貼合地形。寨外兩座營火包含柴木、石圈、明顯跳動的大火舌、上飄火星與逐漸散開的灰墨煙線，動畫同樣由GPU處理。
- 完成山寨後自動進入120秒日夜循環：白晝 → 日落 → 黑夜 → 清晨 → 白晝。太陽移動並轉為橘紅夕陽、沉入山後；入夜後星星漸亮、月亮升起，天亮時再淡出。天空、雲、山寨與地面同步轉暖／轉暗，水面帶出光色，營火在夜間照亮附近地面。
- 日月及星空採世界方向定位，拖曳旋轉時會跟著視角移動，山與寨樓會遮擋後方天體。按 P 同時暫停／繼續日夜及原有動態，隱藏分頁暫停計時；換景保留目前時刻，重播片頭回到白晝。
- 夜空間歇出現流星，淡金墨頭帶出灰藍筆尾，尾跡微彎、寬窄不齊，帶有濃淡墨池、斷墨與散開筆絲，約1.5–2秒內劃過並淡去；各次方向不同，旋轉視角可看見其他方向的流星。流星與天空共用動畫時鐘及繪製批次，白天隱藏、陰雲削弱，P與隱藏分頁會一併暫停。
- 月亮每輪日夜循環更換一次月相，依序為蛾眉月、上弦月、盈凸月、滿月、虧凸月、下弦月、殘月、新眉月，八輪後重複。同一夜保持月形，月亮沉入地平線後才換相；採水墨濕邊與淡月暈，重播回到第一輪眉月。
- 極光以72秒循環在不等寬濕墨雲幕、斷續斜帶與偏斜升騰墨雲之間平滑變化，取消等距直紋與放射光束。同幕混合青綠、藍、紫、玫紅與淡金，主色約125秒輪替；疏密、缺墨、邊緣與色池沿世界方向流動。入夜漸亮、清晨淡去，山峰與寨樓遮擋光帶，陰雨及雪雲會削弱極光；P與隱藏分頁一併暫停。極光與星月共用既有天空批次。
- 春夏必須在本次播放確實經過一場雨，雨停後再留一小段放晴間隔，才會於日光下浮現淡彩虹橋；直接從晴天開始不會憑空出現。彩虹採淺色、低透明度，位於山寨後方並被山峰遮擋；夜間、雨中及關閉天氣時不出現，下一場雨前會先淡去。
- 彩虹以寬窄不齊的淡彩筆掃形成弧線，色彩相互滲化，筆腹帶出缺墨與飛白，濕邊自然散開。
- 右側河流拓寬並向遠山延伸，前景河灣向左多展開一些；地形、水彩、水紋與花床共用同一河道。夜晚水面出現流動的藍眼淚光痕及細小閃點，沿河灣與水流明滅，天亮淡去，冬季與大雨時減弱。
- 黃昏後，城牆、門樓與塔樓的古式燈火漸亮，燈芯微微閃動並染暖附近牆面，清晨再逐漸熄去；燈位固定於建築，隨視角呈現遮擋。
- 四季以240秒循環：春天嫩綠細雨與百花盛開、夏天濃綠陣雨、秋天金橘落葉、冬天退色覆雪與飄雪。每季都有轉晴空檔，季末平滑換色；日夜與季節長度可分別設定。
- 春季寨外兩側、河岸與四周山腳分布約1600株彩墨花卉，呈粉紅、朱紅、淡黃、紫與米白色。前15.6秒由花苞錯落開展，接著盛開，45.6秒後逐漸收淡至入夏；花莖貼地、隨風輕搖，花色隨夕照與月夜變化。花床避開寨門通道、營火、屋舍及河水，保留360°視角的地形遮擋。
- 春夏白天有白圓翼、黃燕尾、藍波緣蝴蝶在花床旁拍翼飛舞，近景大小有限制，避免遮住主要場景。夏夜草叢與岸邊有暖黃綠螢火蟲低空漂移，各自明滅；大雨時減少，秋冬退場。所有昆蟲同樣接受世界空間遮擋並跟隨P暫停。
- 花朵由4–7道偏心、不等大小的濕筆團重疊，有正面與側面花形、大片積墨、濕邊與露紙缺口。蝴蝶左右翼使用各自不同的鬆散筆痕、彎曲輪廓與墨量，拍翼相位略有差異，保留白、黃燕尾、花青三類。
- 雨絲、雪花與翻轉葉片有前後景大小及遮擋，會隨360°視角呈現。雨天雲層轉灰、日月星光減弱，地面與水面更濕亮；冬雪主要積在山脊、地面、屋頂和枝葉，保留寨牆、旗幟與墨線。營火維持暖色。
- 雨中混入120顆彩墨滴，其中40對安排在前景平地。落地先留濃色核心，再由六股不等長的青、藍、紫、朱紅、金黃與碧綠墨流向外暈開並交融，濕邊保留2.2–2.8秒後消散。面積約為前版4倍、濃度加深，夜間仍保留彩色；每個落點以3×3地形網格貼地，固定批次與落地同步時鐘不變，無工整同心彩圈、不無限累積。
- 落葉混合狹長葉、闊葉、銀杏與掌狀葉意象，由不對稱曲筆、缺邊和金黃、赭紅、褐色疊墨構成。雪花改為粉雪、碎絮、破筆與薄片留白，取消規則六角星與幾何冰晶；各類有不同大小、速度、旋轉及飄移。
- P 也會暫停四季及天氣；隱藏分頁停止計時，換景保留季節，重播片頭回到設定的起始季節。開場白紙與故事閱讀不出現天氣粒子。
- 五個鏡頭以平滑環繞過渡銜接，沿安全半徑與地形高度移動，避免直接穿過寨牆。

## 16:9 現場輸出

構圖以 16:9 設計，依最新指定直接滿版：畫布填滿整個視窗，不留黑邊或頁面邊距，非16:9視窗會拉伸完整構圖而不裁切。開場原始塗鴉也拉伸鋪滿完整視野，取消原先91%高度與原圖比例造成的四周留白，並略過原圖最外緣的純白空白、保留全部可見筆畫；旋轉成景的筆觸起點使用同一組滿版座標。Windows 使用「延伸」顯示模式，外接螢幕設為 1920×1080，將瀏覽器移至外接螢幕後按 F11。若之後提供 LED 原生尺寸，可再適配。

筆畫一次上傳GPU；旋轉、換景與重播重用資料。雲、水、旗與鳥由頂點/片段著色器更新，不在每幀重建幾何。筆刷採單次雙面繪製，省去透明材質的重複pass。繪圖上限約210萬像素、DPR上限1.25；有焦點且持續低於40FPS時逐級降低渲染比例，穩定後恢復。隱藏分頁停止循環，暫停動態且無操作時停止重繪；效能數據僅存在canvas dataset，不顯示於舞台。

## 日夜循環設定

日夜設定獨立存於 `dist/day-cycle-config.json`，修改後重新整理即可套用：`enabled` 控制循環開關（false 固定白晝）、`durationSeconds` 為一輪秒數（30–1800，預設120）、`startPhase` 為起始進度（0–1，0白晝、0.34夕陽、0.65夜晚、0.92清晨）。預設0–30秒為白晝、30–57.6秒為日落、57.6–99.6秒為黑夜、99.6–120秒為清晨，光色及天體軌跡在各段之間平滑變化。這是舞台演出的循環時間，不依電腦的實際時鐘；片頭繪製與故事閱讀不計入循環。

## 四季與天氣設定

編輯 `dist/season-config.json` 後重新整理：

- `enabled`：四季開關，false 回到原始場景色彩並停用天氣、春花、蝴蝶及螢火蟲。
- `durationSeconds`：完整四季的秒數，預設240，可設60–3600。預設每季60秒，季末10.8秒漸變到下一季。
- `startPhase`：起始進度0–1，預設0；春雨可用0.06、春花全盛0.12、夏雨0.32、秋葉0.58、冬雪0.84。彩虹預覽從0.33的雨中開始，待雨停後出現，並將日夜`startPhase`設0以提供日光；直接設0.372的晴天不會立即出虹。0、0.25、0.5、0.75各為四季開始的晴朗段。
- `weatherEnabled`：false保留四季顏色、春季開花、蝴蝶、螢火蟲與冬季覆雪，關閉下雨、飄雪、落葉、陰雲、濕地及雨後彩虹效果。
- `weatherIntensity`：天氣強度0–1.5，預設1；0關閉動態天氣。

四季與日夜共用主場景的播放時鐘，各有自己的週期；兩個時鐘都不包含片頭時間。所有天氣採固定GPU粒子批次，總配置雨絲1600、雪花650、葉片180、漣漪120，只有當前天氣的批次會繪製，無每幀重建幾何。
其中120個雨粒作為滴墨，與120個地面墨暈配對；沿用雨絲及漣漪批次，不增加繪製批次或每幀地形取樣。
春花使用兩個固定GPU批次繪製花莖與花瓣，程序水彩花瓣不需額外圖片；換季隱藏，重播重用，P及隱藏分頁一併暫停開花和風擺。
昆蟲以兩個固定批次容納6隻蝴蝶與128隻螢火蟲；藍眼淚以一個水面批次容納120段光痕與260個閃點。只有符合時段的效果會顯示，全部重用幾何與貼地／飛行資料。

## 片頭文字設定

編輯 `dist/intro-config.json` 後重新整理網頁，即可套用文字與時間，不需要網址參數。

- `credits`：依右到左排列，每組的 `role` 是小字職稱、`name` 是大字姓名。預設為「製作人／土撥鼠哥」「主演／南方薪傳」，最多4組，每組職稱6字、姓名8字。
- `showAtRotation`：開始顯示文字時的旋轉進度，預設 `0.28`。原始塗鴉繪製期間不顯示文字。
- `writingSeconds`、`holdSeconds`、`fadeSeconds`：分別為題字寫入、完整停留、墨跡消散的秒數。
- `story.title`、`story.synopsis`：接在製作人／主演之後的故事名稱與簡介。各自最多12／240字；舞台上建議簡介在100字以內。預設完整保留使用者提供的故事原文。
- `story.writingSeconds`、`story.holdSeconds`、`story.fadeSeconds`：故事題名／簡介的寫入、閱讀、退場秒數，預設6／10／1.3秒。
- `storyGapSeconds`：工作人員題字與故事之間的間隔，預設0.6秒。
- `splashEnabled`、`splashIntensity`：潑墨串場開關與濃度，預設開啟、濃度1。
- `drawingSeconds`、`rotationSeconds`：原塗鴉繪製與正常旋轉的秒數；文字閱讀段會自動延長線稿過渡。
- `enabled: false`：關閉製作人／主演題字；`story.enabled: false` 關閉故事。兩者都關閉時，回到17秒塗鴉成景。
- `fontScale`、`story.fontScale`：題字與故事簡介的尺寸倍率，預設1.15／1.45。
- `story.removePunctuation`：預設false，保留使用者原文的全部標點。預設61字依語意排成十個直欄，人名不跨欄拆開。
- `story.columns`：可選的自訂直欄字串陣列，依右到左排列；全部欄拼回後必須與簡介相同，否則回到自動排版。
- `splashAccentColor`、`splashAccentAmount`：朱紅墨色與點綴比例，預設`#a83224`／0.22；設為0可只用黑墨。
- `inkColor`：六位十六進位墨色。
- `letteringStyle`：預設`calligraphy`，採青柳衡山行書；`procedural`可切回筆畫路徑毛筆版本，該字庫目前僅涵蓋漢字，不適用含標點的簡介。

初始化與原塗鴉的底色全部使用純白。依使用者後續要求，題字使用書家青柳衡山親筆書寫的「衡山毛筆行書」，不是標楷體，也不是王羲之字型。原字形的粗細、連筆、收鋒與飛白予以保留，再沿墨跡骨架顯露、滲染、積墨與消散。骨架動畫是藝術化筆跡生長，並非歷史書寫筆順的精確重演。所有文字維持繁體，載入前用實際非空字形清單檢查每字；不讓缺字自動混用系統字體。

行書WOFF2及字元清單存於`dist/assets/fonts/`，官方來源與說明見`KouzanGyousho-SOURCE.md`。字體只由本機載入，不需安裝到Windows，也不需外部CDN。使用者提供的原文61字包含全形逗號及句號；目前所需55種漢字與兩種標點全部有字形。
黑墨與少量朱紅的潑墨串接三段轉場；閱讀期間下緣與邊角的墨流持續變形、聚散，中央文字保持清楚。整個過場使用一個額外畫面批次，沒有每幀重建幾何；文字與過場結束後全部隱藏，不增加完成場景的繪製批次。

備用程序毛筆的漢字筆畫資料在`dist/assets/ink-strokes/`，附來源與授權；從Hanzi Writer資料只保留筆順中心線，外形由此專案的毛筆程序生成。預設文字合併成小檔，修改JSON後會從本機分片字庫補載所需文字，不連外。若設定字不在字庫，開發者主控台會列出缺字並停用該段題字，場景仍播放；不擅自替換為一般字型。
